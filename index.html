Join code·····

On each team computer, open this same game file or web address and choose Join a game, then type the code. Each team can have one computer or many. At the start of each round the buzzers open; the first team to buzz types their answer, and the board checks it.

Team buzzers need the downloaded game file opened in a regular web browser. They can't connect from inside Claude.

Save your work

Saves your topics, questions, settings and any game in progress, so you can load them on another computer.

How a round works

  1. Face-off. One player from each team comes up. Whoever names the higher answer wins control for their team. Tap that team's score panel.
  2. Play. The team in control takes turns guessing. Correct answers flip over and add to the round points.
  3. Three strikes. After three wrong answers, the other team huddles and gets one guess to steal every round point.
  4. Win. The team with the most points after the last round wins.

Hosting: tap a tile to reveal it, or type a student's guess in the box and the game checks it against the answers, so the host doesn't need to know them. Keyboard: 1–8 reveal, X strike, Z undo, N next round.

Topics & questions

Topic

Up to 8 answers per question. "Also accept" lists other words that count when you type a guess (separate them with commas). The sample questions use made-up numbers; survey your own students for real ones. Questions save in this browser automatically.

Copy or paste a whole topic
