# Survey Showdown

A two-team survey guessing game for the classroom display.

**Play:** https://mp42871.github.io/survey-showdown/

- Open the page on the classroom display, tick **Let teams buzz in and answer from their own computers**, and start a game.
- On each team computer, open the same page, choose **Join a game**, and type the join code shown on the board.

The whole game is the single file `index.html`. Team computers connect through the free PeerJS service, so every computer needs internet access.
